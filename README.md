# AiFinVerse 🚀

**AiFinVerse** is an intelligent, AI-powered financial advisor and expense tracker designed to help users manage their personal finances, track expenses, and receive personalized investment advice. Built using the MERN stack (MongoDB, Express.js, React, Node.js) and integrated with advanced AI models for financial insights.


## 🌟 Key Features

* **🤖 AI Financial Advisor:** Chat with an AI assistant to get personalized financial advice, budget tips, and investment explanations.
* **📊 Expense Tracking:** Log daily expenses, categorize transactions, and view spending habits via interactive charts.
* **🔐 Secure Authentication:** User registration and login using JWT (JSON Web Tokens).
* **📈 Visual Dashboards:** Real-time data visualization of income vs. expenses.
* **📱 Responsive Design:** Fully optimized for desktop and mobile devices.

## 🛠️ Tech Stack

**Frontend:**
* React.js
* Chart.js / Recharts (for data visualization)
* Tailwind CSS / Material UI
* Redux / Context API (for state management)

**Backend:**
* Node.js
* Express.js
* MongoDB & Mongoose
* JWT (Authentication)

**AI Integration:**
* OpenAI API / Gemini API (or your specific ML model)
